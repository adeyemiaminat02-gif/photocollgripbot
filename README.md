# Photo Collage Grid Bot (@photocollgripbot)

A production-ready Telegram Bot written in Python that accepts photos from users and generates clean, customizable grid collages in real time.

## 🚀 Features

- **Custom Grid Layouts:** 2×2, 3×3, 4×4.
- **Configurable Settings:** Custom spacing, white/black background, and resolution levels.
- **Auto Image Fitting:** Smart proportional center cropping using Pillow.
- **Privacy First:** Temporary photos are deleted automatically immediately after creation or cancellation.
- **Render Ready:** Includes a built-in health check web server and periodic memory cleanup.
